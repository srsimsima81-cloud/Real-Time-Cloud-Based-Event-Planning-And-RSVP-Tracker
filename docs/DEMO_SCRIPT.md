# 5-minute demonstration script

1. Open the login page and sign in as the fictional organizer.
2. Show the organizer dashboard and create/select Cloud Computing Workshop.
3. Open two additional browser windows and sign in as Attendee A and B.
4. A chooses GOING; return to organizer screen and show live count.
5. B chooses MAYBE; show live Maybe count.
6. B changes to GOING; show counts change without refresh.
7. Organizer publishes an announcement.
8. Show attendee notification.
9. Demonstrate a small-capacity event and waitlist behavior.
10. Open `/docs` to show REST API documentation.
11. Show GitHub repository, test output and cloud architecture diagram.
